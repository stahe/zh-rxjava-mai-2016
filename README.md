## 📘 概述

本文档面向希望学习并实践使用 **RxJava** 及其变体进行 **响应式编程** 的资深 Java 开发者。

与传统的理论化方法不同，本文内容主要基于 **具体示例**，每个示例均配有详细说明，并遵循连贯的教学路径。

---

## ⚙️ 背景与目标

响应式编程旨在简化：

* 异步处理
* 数据流处理
* 事件管理

本文基于 **ReactiveX** 生态系统，该生态系统为异步编程提供了面向可观察流的 API。

## 🔁 ReactiveX 与 RxJava

ReactiveX 是一组用于处理 **可观察数据流** 的库。

### 涉及的库

本文重点介绍：

* **RxJava**：Java 实现版本
* **RxAndroid**：Android 应用扩展
* **RxSwing**：Swing 界面扩展

---

## 🧠 涉及的概念

* 异步编程
* 高级观察者模式
* 数据流（Observable）
* 函数式运算符
* 异步错误处理
* 简化的并发处理

这些概念乍看之下可能比较复杂，但我们将通过详细的示例逐步进行讲解。
